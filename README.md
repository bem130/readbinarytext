# Read Binary Text

明暗の画像からASCII文字列を読み取る、スマートフォン向けのミニゲーム。`index.html` だけで動作し、外部ライブラリ・画像・フォントは使用しない。配色・カード・ボタン・開始画面は、隣接する `automatajudge` に合わせている。

## 遊び方

- 左から1列が1バイト（1文字）。明色は1、暗色は0。
- 最上段は `11001100…` のタイミングパターン。
- 次の8段は上からビット7、6、5、4、3、2、1、0（MSBから）。重みは128、64、32、16、8、4、2、1。
- 最下段は暗色の余白。1列は計10段。
- 表示形式は [bem130/visualBinary](https://github.com/bem130/visualBinary/blob/main/index.html) の `drawBinaryImage` を参照した。参照先のUTF-8形式のうち、ゲームではASCII英大文字 A〜Z を出題する。
- 1文字の練習後、2〜6文字の文字列を全8問解読する。入力は小文字も受け付ける。時間制限なし。
- 出題候補は英単語・略語・国や地域のコードの計1100候補（2文字200候補、3文字250候補、4文字250候補、5文字200候補、6文字200候補）。既存の220候補をすべて残して5倍に拡張した。2・2・3・3・4・4・5・6文字の順にランダムに選び、同じプレイ内では重複しない。
- 2文字の追加候補には [ISO 3166の国・地域コード](https://www.iban.com/country-codes)（JP、GB、CAなど）を含む。
- 早見表はA〜Zのビット画像を表示する。問題と同じ配色・ビット順で、データ8段の明暗を直接比較できる。

## 採点

文字数を `L`、基本点を `B = 10 × L`、不正解の回数を `W`、回答までの秒数を `t` とする。

- 基本点：`B × max(0, 1 − 0.2 × W)`。不正解1回につき元の基本点の20%を減点し、最低0点。
- 初回正解ボーナス：不正解なしで正解すると `B` 点。早見表を使っても対象になる。
- コンボボーナス：早見表なしの初回正解が連続して `C` 回続いたら、`B × (C − 1) / 10` 点。不正解、早見表の使用、答えの表示でコンボが終了する。
- 速度倍率：`0.15 + 9.85 / (1 + (t / T)^2.5)`（`T = 1 + 0.8 × L` 秒）。基本点・初回正解・コンボの合計に掛ける。0秒の10倍から滑らかに減少し、長時間では0.15倍に近づく。時間切れはない。
- 早見表を使った問題は、速度倍率を掛けた得点を60%にする。再度開いても重ねて補正しない。
- 小数は途中で丸めず、最終的な問題ごとの得点を四捨五入する。答えを表示した問題と練習は0点。5回以上不正解になった問題も0点になるが、解読は続けられる。
- 空欄・文字種・文字数の誤りは不正解に数えず、初回正解の資格とコンボも維持する。

計測は各問題を表示して入力欄へ移動した直後から回答まで。早見表や入力エラー、別タブを見ている時間も含み、解説・結果画面の時間は次の問題に持ち越さない。単調増加時計 [`performance.now()`](https://developer.mozilla.org/en-US/docs/Web/API/Performance/now) を使う（端末のスリープ中の進み方は環境に依存する）。

配点は「通常100〜500点、上手い人1000点前後、普通の文字のように流暢に読める人5000点前後」を目標に調整した。次の時間は実測ではなく仮の基準であり、実際のプレイヤー層を保証するものではない。全8問を初回正解・早見表なしで解き、各問の所要時間を `1秒 + 1文字あたりの秒数 × 文字数`（入力・回答操作を含む）とした場合：

| 想定 | 1文字あたりの時間 | 全8問の得点 |
| --- | ---: | ---: |
| 通常・ゆっくり | 8秒 | 148点 |
| 通常 | 5秒 | 231点 |
| 通常・慣れてきた | 3秒 | 504点 |
| 上手い | 2秒 | 1020点 |
| 流暢 | 0.5秒 | 4947点 |

理論上限は7050点（全問0秒・初回正解・早見表なし）。初回正解とコンボの優遇は維持し、得点の大部分を速度に依存させた。全問正解でも速さで大きな差がつく。ただし整数への丸めにより、小さな時間差が同点になることはある。

## 操作と読み上げ

- 回答は「答える」のタップ、または入力欄のEnterキーで確定する。IMEの変換確定中とEnterキーの長押しによる反復では判定しない。
- 問題の画像には、各列のデータ8ビットを上から順に読み上げる説明を付ける。解読後の文字列は説明に含めない。早見表では、各文字に対応する8ビットを読み上げる。
- 早見表を開くと見出しへ移動する。「入力に戻る」で入力欄へ戻れる。入力途中の内容を保持し、同じ問題で早見表を再度開いても追加の減点はない。
- 本番・練習の開始時と次の問題へ進んだときは、入力欄へ自動でフォーカスと表示位置を移す。結果・タイトルへの移動時は、その画面の見出しにフォーカスを移す。
- 回答後は「次の文字列へ」（最終問は「結果を見る」、練習では「本番を始める」）へフォーカスを移す。答え・獲得点・継続中のコンボを含む結果の文章を、そのボタンの読み上げ説明として関連付ける。基本点が0点の状態で不正解になった場合は、追加の減点がないことを表示する。
- 図中のラベルは標準設定で16 CSS px相当とし、画面の高さに合わせて縮小しない。文字サイズに連動するrem単位で図を表示し、幅が足りない場合は図の領域を横にスクロールできる。

## 確認

```sh
node tests/game.test.cjs
```

実際のHTML内のJavaScriptを読み込み、全ASCIIコードのビット順とSVGの色、タイミング行、余白、1100候補の件数・文字数・文字種・重複、問題構成、採点、再挑戦、スコア通知を検査する。読み上げ用ビット列、フォーカスとスクロールの移動先、早見表との往復での入力保持・減点、フォームを使わないクリック・Enter回答、IMEとキー反復の除外も検査する。DOMはスタブであり、実際のブラウザ描画、スマホのキーボード、VoiceOver、sandbox付きiframe、swipla上の実動作はこのテストの対象外。
